Privacy Policy

Last updated: September 2026

This is a simple portfolio website for faeridoodles (erin-rose rigaud). It's built to keep things minimal — here's exactly what happens with your data when you visit.

What this site collects

This site does not use cookies, does not run analytics or tracking scripts, and does not have any sign-up forms or accounts. Nothing you do on this site is stored by me.

Hosting

This site is hosted on GitHub Pages. GitHub may automatically log standard server information (like IP address and browser type) for security and performance purposes, independent of anything I control. You can read GitHub's own policy here: GitHub Privacy Statement.

Fonts

This site loads fonts from Google Fonts, which may log basic request data (like your IP address) as part of serving the font files. See Google's Privacy Policy for details.

If you contact me

If you email me for a commission or inquiry, I'll only use your email address and message to respond to you. I won't share it with anyone else or add you to any mailing list.

Changes

If this policy ever changes (for example, if analytics or a contact form is added later), this page will be updated to reflect that.
